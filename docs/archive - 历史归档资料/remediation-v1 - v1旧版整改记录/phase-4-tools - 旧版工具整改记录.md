# Phase 4：Tool 初始化和最小调用闭环

<!-- 所属目录：remediation-v1 - v1旧版整改记录 -->

阶段状态：待处理  
最后更新：2026-07-15  
对应问题：TOOL-1

## 1. 阶段目标

不一次性实现完整工具平台，先让一个真实、只读、可验证的 Tool 完成注册、授权、参数校验、执行、结果回传和审计闭环。

## 2. 修改前事实

- `ensureToolsInitialized()` 已定义，但当前没有调用点；
- Tool API 直接读取空 Registry；
- Web Search 和 Knowledge Search 仍返回占位文本；
- Calculator 描述支持的部分表达式与清洗逻辑不一致；
- 工具输入没有统一 Zod Schema、超时和 capability 授权。

## 3. 最小实现范围

建议首个真实工具选择确定性、只读能力，例如日期时间或基于服务端文档库的知识检索。

- [ ] API 入口幂等初始化 Registry；
- [ ] Tool 定义包含稳定 ID、说明、Zod input/output Schema；
- [ ] 校验当前 Agent 是否具备对应 capability；
- [ ] 限制调用次数、超时、输入和输出大小；
- [ ] 使用 `toolCallId` 记录执行；
- [ ] Tool 失败返回结构化错误；
- [ ] 模型最多执行有限轮次；
- [ ] 占位工具不得显示为已可用能力。

## 4. 暂不进入本阶段

- 任意网页抓取；
- 外部写操作；
- 运行用户代码；
- 无限工具循环；
- 仅靠文本正则模拟完整原生 Tool Calling；
- 未经许可的文件系统或网络访问。

## 5. 验收矩阵

- [ ] 未初始化时 API 仍可安全完成幂等初始化；
- [ ] 未授权 Agent 调用被拒绝；
- [ ] 非法参数在执行前被拒绝；
- [ ] 工具超时后图可终止；
- [ ] 同名并发调用通过 `toolCallId` 区分；
- [ ] 工具结果不携带密钥或原始内部错误；
- [ ] 最大轮次后必定停止；
- [ ] 列表 API 只返回安全元数据。
