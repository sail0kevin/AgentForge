# 质量评测材料
<!-- 文件名：README - 质量评测说明 -->
<!-- 所属目录：quality - 质量评测 -->

本目录保存可复核的评测方案与已解盲的汇总结论，不保存模型密钥、用户数据、未解盲映射或原始候选报告。

- [盲评实验协议](blind-evaluation-protocol - 真实模型盲评协议.md)：P2-4 的正式采样、匿名评分、解盲和结论边界。
- `results/`：只在完成独立评分、解盲和复核后放入汇总报告；当前没有真实模型结果。

本地执行期间，把运行原文、匿名评分包、私有解盲表和评分表放在 `local-only/blind-evaluation/`，不得提交。
