# 2026-08-04 - generated-atelier - AgentForge 生成说明

## 案例定位

这是基于 AgentForge Product/UI 报告生成的第二个可运行产品案例：一个数字艺术展览网站。

- 路由：`/generated/atelier`
- 品牌：ATELIER
- 展览：`Soft forms / Hard light`
- 产品类型：艺术机构 / 展览体验 / 作品浏览
- 视觉关键词：编辑型排版、全屏图像、强对比色、留白、章节叙事、作品详情状态

该案例的目的，是验证 AgentForge 生成的报告不只适用于普通企业后台，也可以约束一个具有品牌个性、叙事结构和美术方向的真实网页产品。

## 报告到页面的映射

| Product/UI 报告内容 | 当前页面实现 |
| --- | --- |
| 产品定位 | 页面被实现为数字艺术展览入口，而不是 SaaS Dashboard |
| 设计方向 | 黑色、象牙白、朱红、钴蓝、荧光绿，多色构成和编辑型大标题 |
| 页面蓝图 | 首屏 Hero、展览导语、作品墙、章节叙事、Visit 区域、页脚追踪说明 |
| 用户流程 | 进入展览 → 阅读宣言 → 浏览作品 → 打开作品详情 → 切换章节 → 规划访问 |
| 交互状态 | 移动端导航展开、声音开关状态、作品详情弹层、章节切换和当前项高亮 |
| 响应式规则 | 桌面三列作品构图，移动端改为单列；导航和作品弹层适配窄屏 |
| 验收要求 | 图片可加载、页面可访问、交互可用、移动端无横向溢出 |
| 证据追踪 | 页脚显示 `Generated from AgentForge Product/UI reports`，并标出 `experience / visual / engineering` |

## 已实现

- 真实图片资产已放入 `public/atelier/` 并用于 Hero、作品卡片和 Visit 区域。
- 已实现艺术展览首屏、展览宣言、精选作品区、三章节叙事区、访问区和页脚。
- 已实现 3 个作品卡片的详情弹层。
- 已实现章节上一章、下一章和直接选择。
- 已实现桌面导航、移动端菜单、声音开关状态。
- 已实现桌面端和移动端截图。

## 目标设计 / 尚未实现

- 声音开关目前是交互状态演示，尚未接入真实展览音轨。
- Visit 按钮目前是视觉入口，尚未接入真实预约系统、地图或票务 API。
- 作品数据目前是演示数据，尚未由报告中心动态注入。
- 当前页面展示了报告驱动结果，但尚未实现“从一份 Product/UI 报告一键编译成任意风格网站”的通用渲染器。
- 图片来自公开图片资产，仅用于产品视觉验证；正式上线前应替换为具有明确授权的展览素材。
