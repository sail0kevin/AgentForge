# 2026-08-04｜NOCTURNE 数字聆听室｜AgentForge Product/UI 报告映射说明

## 定位

NOCTURNE 是 AgentForge `visual_first` 产品/UI 方案生成方向的第三个可运行案例。它不是后台管理系统，而是一个面向数字艺术、声音和视觉内容的沉浸式内容产品。

## 已实现

- `/generated/nocturne` 路由可直接访问，生产构建已通过。
- 沉浸式首屏：主视觉、作品上下切换、当前作品播放/暂停状态。
- 内容浏览：Rooms 区域支持 `all`、`sound`、`image` 三种筛选。
- 内容卡片：作品图片、作者、媒介、时长、说明和收藏状态。
- 详情流程：点击 `Open room` 打开详情弹层，可关闭并切换播放状态。
- 响应式布局：桌面端双栏沉浸式构图，移动端改为单列流式内容和可展开导航。
- 视觉资产：复用项目内已审核的艺术图片资产，未编造外部数据或效果数字。

## 报告到页面的对应关系

| Product/UI 报告要素 | 页面落地 |
| --- | --- |
| 视觉优先方案 | 深色画布、编辑式排版、非对称首屏、艺术图片和章节化内容 |
| 首页蓝图 | Header、Hero、Rooms、Field notes、About、Footer |
| 核心流程 | 进入房间 -> 选择媒介 -> 播放/暂停 -> 收藏 -> 打开详情 |
| 组件策略 | 作品卡片、筛选 Tabs、播放控制、收藏按钮、详情弹层、移动端菜单 |
| 状态设计 | 当前房间、播放中、已收藏、当前筛选、菜单展开、弹层打开 |
| 响应式规则 | 980px 以下折叠构图，640px 以下单列布局并启用移动导航 |
| 验收矩阵 | 路由可访问、构建通过、交互可点击、移动端无横向溢出 |
