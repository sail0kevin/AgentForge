## 一、项目快速了解

这是一个**本地多智能体工作平台**，核心功能是：
- 用户手动创建 Agent（配置模型 API Key、API URL、模型名称）
- 在对话空间中发送消息，多个 Agent 按顺序回复
- 支持 Ollama（本地）、OpenAI Compatible、DeepSeek、Anthropic 等模型供应商
- 数据持久化到数据库（当前 SQLite，可切换 PostgreSQL）

**核心交互流程：**
`
创建 Agent → 在对话空间发送消息 → 消息存入数据库 → 按顺序调用每个 Agent 的模型 → SSE 流式返回 → 前端显示回复
`
