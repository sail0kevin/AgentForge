# 2026-07-09 v0.1 收口验证记录

## 本次目标

围绕 v0.1 本地稳定版做一次交付前收口，重点确认项目不再依赖默认演示 Agent，并且核心聊天链路仍然可用。

## 本次修改

- 将 `src/lib/demo-data.ts` 改成空的本地工作台初始状态。
- 删除代码层面的默认演示 Agent 初始数据，避免用户第一次打开页面时出现预设 Agent。
- 调整 `/api/seed` 接口，不再向数据库种入默认演示 Agent，也不再创建演示欢迎消息。
- 更新页面 metadata，将浏览器标题从 `Create Next App` 改为 `Multi-Agent Workspace`。
- 将根页面语言标记调整为 `zh-CN`，更贴合当前默认中文界面。

## 当前已验证

以下命令已经通过：

```bash
npm run lint
npx tsc --noEmit
npm run build
npm run smoke:manual
```

`npm run smoke:manual` 覆盖了以下主链路：

- 单个无 API Key Agent 进入模拟回复。
- 两个启用 Agent 按顺序回复。
- 禁用 Agent 被跳过。
- 错误模型服务返回失败消息，但运行仍然完成。

本地页面 `http://localhost:3000/` 已确认返回 HTTP 200。

## 当前结论

当前版本符合 v0.1 本地 MVP 的核心要求：

```text
手动创建 Agent -> 输入消息 -> 用户消息立即显示 -> 启用 Agent 收到输入 -> Agent 回复显示
```

它可以给别人做本地试用，但仍不应描述为正式生产 SaaS。数据库持久化、账号系统、API Key 加密保存、真实 RAG、真实工具调用、长期记忆、语义缓存和桌面端打包仍属于下一阶段。
