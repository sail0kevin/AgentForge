# v0.1 稳定版开发计划

## 目标

将项目从"功能已经打通但体验不稳定"推进到"本地可稳定使用、可交给别人试用"的 v0.1 版本。

优先级只围绕一条主线：创建 Agent -> 输入消息 -> 用户消息立即显示 -> 启用 Agent 收到输入 -> Agent 回复显示。

本阶段不接入复杂 RAG、LangChain、LangGraph、正式账号系统，也不让数据库成为聊天主流程的硬依赖。

## 验收标准

1. 
pm run lint 通过
2. 
px tsc --noEmit 通过
3. 
pm run build 通过
4. 打开 http://localhost:3000/ 页面正常
5. 未创建 Agent 时，输入框可见
6. 未创建 Agent 时发送消息，用户消息气泡立即显示，并提示需要添加或启用 Agent
7. 创建 Ollama Agent，API Key 留空，模型名填写本机已有模型，发送消息后能收到回复
8. 创建 OpenAI-compatible Agent，填写 API URL、API Key、模型名后能收到回复
9. 同时启用两个 Agent，发送一条消息后两个 Agent 都回复
10. 禁用其中一个 Agent 后，它不再回复
11. API URL 错误或模型服务未启动时，聊天区显示清楚的失败消息
12. 刷新页面后，本地 Agent 配置仍然存在
